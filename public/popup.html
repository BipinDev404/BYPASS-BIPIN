How to Use & Install

1. Install as Extension

Export this project as a ZIP (from the top-right menu), extract it, and open chrome://extensions in your browser. Enable Developer mode and click Load unpacked to select the folder.

2. Initial Setup

Set your Name, Master Password, and a Security Question. This is stored securely offline in your browser. If you forget your Master Password, click "Forgot Password?" to use the recovery question.

3. Manage Vault (Import/Export)

Click New Password + to add an account. Click the lock icon next to an item to copy its password. Use the Import and Export buttons near the search bar to backup or restore your vault from a JSON or CSV file.

4. Password Generator (Gen)

Clicking Gen generates a 16-character cryptographic string using a pool of uppercase, lowercase, numbers, and special symbols, making it virtually unguessable.
